# Тесты API

Тесты отправляют HTTP-запросы обработчикам `/account` и `/transaction` через `httptest`. Они используют временную SQLite-базу и заглушку Redis: ничего кроме теста запускать не нужно. Настоящая база проекта не затрагивается.

Из корня проекта:

```sh
cd api
go test ./tests -v
```

Для запуска одного теста, например перевода:

```sh
go test ./tests -run '^TestTransfer$' -v
```



Параллельные списания можно проверить с парамерами:

```sh
go test ./tests -run '^TestConcurrentTransfersCannotOverdraw$' -count=20 -v -timeout=60s
```




Если команда долго не выводит результат, сборка зависимостей или их загрузка может ещё выполняться. 
Добавьте `-x`, чтобы увидеть этапы сборки. 
Флаг `-timeout` ограничивает выполнение уже собранного тестового процесса, но не время сборки и загрузки зависимостей.
